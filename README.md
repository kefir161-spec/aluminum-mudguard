# Конфигуратор алюминиевой грязезащиты (MVP)

Рабочий локальный MVP-конфигуратор полотна из 4 базовых профилей:

- `rubber` — профиль с резиной
- `pile` — профиль с ворсом
- `brush` — профиль со щеткой
- `scraper` — алюминиевый профиль-скребок

Комбинации реализованы через шаблоны раскладки (presets), а не как отдельные товары.

## Стек

- React + TypeScript
- Vite
- Zustand
- SVG renderers (вид сверху, технический лист)
- LocalStorage
- Экспорт PDF/PNG (`jspdf`, `html-to-image`)
- Vitest (unit-тесты доменной логики)

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес из консоли Vite (обычно `http://localhost:5173`).

## Проверки

```bash
npm run lint
npm run test
npm run build
```

## Что реализовано

- Редактирование размеров полотна (ширина/длина)
- Сборка полотна из 4 базовых типов профилей
- Добавление полос, изменение типа
- Автозаполнение остатка выбранным типом
- Шаблоны раскладки с повторением паттерна до заполнения ширины
- Расчёты: площадь, количество полос, разбивка по типам, ориентировочная стоимость, контроль заполнения ширины
- Вкладки: `Конструктор`, `Чертёж`, `Спецификация`
- Экспорт технического листа в PDF и PNG
- LocalStorage: сохранить/загрузить/удалить проект, загрузить демо-проекты

## Демо-проекты

- Входная группа ТЦ — Резина–Ворс
- Офис — Ворс–Скребок
- Интенсивный вход — Резина–Щетка–Скребок

## Структура

```text
src/
  app/           — корневой UI
  components/    — панели и элементы управления
  data/          — демо-проекты и текстуры профилей
  domain/        — расчёты, раскладка, валидация
  export/        — экспорт PDF/PNG
  renderers/     — SVG-рендеры и чертёж
  storage/       — LocalStorage
  store/         — Zustand store
scripts/
  slice-profile-image.py — регенерация PNG-ассетов профилей
```

## Примечание

Расчёт стоимости в MVP выполняется по демонстрационным ценам и подлежит уточнению.
